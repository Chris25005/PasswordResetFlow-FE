Password Reset Flow – Frontend
This is the frontend application for the Password Reset Flow project.
It provides a user-friendly interface for requesting a password reset link and updating the password securely using token-based verification.
The frontend is built with React (Vite) and communicates with a Node.js + Express backend deployed on Render.
________________________________________
🛠 Tech Stack
•	React 18
•	Vite
•	React Router DOM
•	Axios
•	Bootstrap 5
•	HTML5 / CSS3
________________________________________
✨ Features
•	Forgot Password screen to request reset link
•	Email validation before submission
•	Secure password reset using tokenized URL
•	Displays success and error messages clearly
•	Responsive UI using Bootstrap
•	Proper routing for reset link (/reset-password/:token)
•	Handles invalid / expired tokens gracefully
•	Production build deployed on Netlify
